# 《台灣夜市摸麻將》（MoMaJohn）更新說明

夜市持續加碼！這次更新讓手機操作更集中，也讓下注與本局進度更容易查看。

## 最新調整

- 手機版下注按鈕移到 HUD 與棋盤之間，倍率狀態更醒目。
- 摸牌後仍可開啟下注視窗查看本局倍率、已選下注與目前進度，但不能修改。
- 本局狀態整合進下注視窗，不再占用獨立按鈕。
- 「點數獲得方式」與「事件一覽」合併為單一「說明」入口。
- 狂歡模式的說明會自動隱藏不適用的事件內容。
- 手機摸牌區下方只保留「說明」與「回主選單」。
- 本局點數直接呈現倍率後的即時結果，遊戲畫面不再顯示內部計算術語。
- 補牌命中時立即成功，不必繼續選完剩餘牌。
- 單局結算與最終成績維持精簡易讀。

既有連線、牌型、事件、倍率與下注數值均維持不變。
